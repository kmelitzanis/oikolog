restaurant_menu

Εισαγωγή συνταγών από URL και εβδομαδιαίο πρόγραμμα γευμάτων που στέλνει τα υλικά στη λίστα αγορών.

directions_car

Οχήματα

Χιλιόμετρα, υπενθυμίσεις σέρβις, ιστορικό εργασιών, κόστος ανά χιλιόμετρο — και διάγνωση OBD μέσω Bluetooth.

Για όλη την οικογένεια

Ένα σπίτι, ένας λογαριασμός — για όλους.

Φτιάχνεις μια οικογένεια και οι υπόλοιποι μπαίνουν με έναν κωδικό πρόσκλησης. Από εκεί και πέρα όλοι βλέπουν το ίδιο σπίτι.

  • group_addΠρόσκληση με κωδικό, ρόλοι ιδιοκτήτη και μέλους, μεταβίβαση ιδιοκτησίας
  • sync_altΚοινοί λογαριασμοί, έσοδα, λογαριασμοί χρημάτων και οχήματα — ό,τι δεν μοιράζεσαι μένει ιδιωτικό
  • notifications_activeΕιδοποίηση στο κινητό όταν κάποιος πληρώσει, και ποιος πλήρωσε τι
  • historyΡοή δραστηριότητας: ποιος πρόσθεσε ή άλλαξε τι

Συνταγές

Επικόλλησε έναν σύνδεσμο. Η συνταγή γράφεται μόνη της.

Δίνεις το link μιας συνταγής και το Oikolog τη διαβάζει από τη σελίδα: όνομα, φωτογραφία, μερίδες, χρόνοι, υλικά και βήματα — μαζί με τις ενότητές τους.

  • linkΔουλεύει με τα περισσότερα μεγάλα sites συνταγών (όσα δημοσιεύουν δομημένα δεδομένα συνταγής)
  • starΕιδική υποστήριξη για το akispetretzikis.com
  • straightenΕλληνικές μονάδες (κ.σ., κ.γ., φλ., γρ.) αναγνωρίζονται και κανονικοποιούνται
  • calendar_view_weekΕβδομαδιαίο πρόγραμμα γευμάτων — και τα υλικά της εβδομάδας στη λίστα αγορών με ένα κλικ

Self-hosted

Τα δεδομένα σου, στο δικό σου σπίτι.

Το Oikolog τρέχει στον δικό σου server, NAS ή VPS. Οι λογαριασμοί και οι πληρωμές σου δεν περνούν από κανέναν τρίτο.

Εγκατάσταση

Σε λειτουργία σε λίγα λεπτά.

Χρειάζεσαι μόνο Docker. Το image περιλαμβάνει την εφαρμογή έτοιμη· η βάση MySQL έρχεται με το compose.

Για NAS, HTTPS και ειδοποιήσεις, δες τον οδηγό Docker.

Κατέβασε το project

git clone https://github.com/kmelitzanis/oikolog.git cd oikolog

Όρισε τα στοιχεία σου

cp .env.example .env docker run --rm kostasmel/oikolog-app php artisan key:generate --show # βάλε το κλειδί στο APP_KEY, μαζί με APP_URL και κωδικούς βάσης

Ξεκίνα

docker compose up -d docker compose exec app php artisan make:user --admin

Άνοιξε το http://localhost:8000 και συνδέσου.

Δωρεάν, για πάντα.

Το Oikolog είναι ανοιχτού κώδικα. Αν σου είναι χρήσιμο, ένα αστέρι στο GitHub βοηθάει να το βρουν κι άλλοι.
